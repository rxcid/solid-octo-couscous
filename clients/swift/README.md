# MusicSampleGraphClient

A Swift client for the Music Sample Graph API, for Sinc. Its types and raw
client are generated at build time by [swift-openapi-generator] from
[`openapi.json`](Sources/MusicSampleGraphClient/openapi.json); `SampleGraphClient`
wraps them in one method per endpoint.

```swift
import MusicSampleGraphClient

let api = SampleGraphClient(serverURL: URL(string: "http://localhost:4000")!)

// A ShazamKit match -> the catalog's recordings of that song.
let match = try await api.resolve(isrc: item.isrc, title: item.title, artist: item.artist)
guard let song = match.tracks.first else { return } // not in the catalog

let dna = try await api.relationships(id: song.id)           // .sources, .derivatives
let crowd = try await api.siblings(id: song.id)              // who else used the same sources
let tree = try await api.lineage(id: song.id).tree           // generations back, as a tree
let fanOut = try await api.lineage(id: song.id, direction: .derivatives)
```

Ids are Sinc's catalog canonical ids, so a `node_…` id from the bundled
catalog works here unchanged. Segment times come in milliseconds, with
`atInSource`, `atInDestination`, and `duration` as `TimeInterval` seconds.
Errors the API answers with arrive as `SampleGraphError` (`statusCode`,
`code` such as `track_not_found`, `message`).

## Adding it to Sinc

Sinc's project is generated by XcodeGen, so add the package in `project.yml`:

```yaml
packages:
  MusicSampleGraphClient:
    path: ../music-sample-graph/clients/swift
targets:
  Sinc:
    dependencies:
      - package: MusicSampleGraphClient
```

The generator runs as a build plugin. Xcode asks once to trust it; command-line
and Xcode Cloud builds need plugin validation skipped, e.g. in
`ci_scripts/ci_post_clone.sh`:

```sh
defaults write com.apple.dt.Xcode IDESkipPackagePluginFingerprintValidatation -bool YES
```

## When the API changes

From the repository root, with Postgres running (`npm run db:up`):

```sh
npm run openapi            # re-export openapi.json; the backend tests fail until you do
npm run openapi:fixtures   # re-record the responses these tests replay
cd clients/swift && swift test
```

The tests replay real server responses and check the client asked for the
URL each was recorded from. To also run against a live server with Sinc's
catalog imported:

```sh
SAMPLE_GRAPH_URL=http://localhost:4000 swift test
```

[swift-openapi-generator]: https://github.com/apple/swift-openapi-generator
